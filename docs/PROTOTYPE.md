# Retrostation UI 原型说明

浏览器打开 `prototype/index.html`（或本地起个静态服务）即可交互。

```bash
cd prototype && python -m http.server 8899
# → http://127.0.0.1:8899/
```

---

## 1. 原型是什么

- **1:1 尺寸**：两块屏幕严格 640×480（RG DS 实测分辨率），按设备物理布局上下排列
- **三视图**：游戏页支持 列表 / 网格 / 封面轮播，`X` 键循环（真机同键位）
- **双屏联动**：上屏是交互主控，下屏是上下文面板，选中项变化后下屏 90ms 节流刷新（模拟真机策略）
- **下屏媒体区**：视频优先（CSS 动画模拟）→ 缺则封面 → 再缺 Logo；可点页签手动切换
- **gamelist 可视化**：侧栏实时显示选中游戏在 `gamelist.xml` 中的 ES-DE 条目
- **全键位可达**：所有功能都能用键盘模拟手柄完成；鼠标/触摸点击是加分项
- **数据真实规模**：平台、ROM 数、封面覆盖率均取自真机 `/mnt/mmc/Roms` 实测
- **封面 / Logo 用程序化占位图**（确定性渐变 + 首字 / 文字横幅），不依赖外部图片资源

> 原型用于**验证信息架构、布局密度、双屏分工和交互节奏**；真机实现见 `docs/DESIGN.md`。

## 3. 键盘 / 手柄映射

| 键盘 | 手柄 | 行为 |
|---|---|---|
| `↑` `↓` | D-pad 上下 | 上/下一个（列表 ±1，网格 ±4；按住连发） |
| `←` `→` | D-pad 左右 | 平台页切平台；列表 ±10；网格 ±1 |
| `PgUp` `PgDn` | L1 / R1 | 翻页 |
| `Home` `End` | L2 / R2 | 跳到首项 / 末项 |
| `Enter` | **A** | 进入平台 / 启动游戏 |
| `Backspace` | **B** | 返回 |
| `Y` | **Y** | 收藏 / 取消收藏 |
| `X` | **X** | **三视图循环：列表 → 网格 → 轮播** |
| `V` | *（无对应按键）* | 副屏视频 开 / 关（关则显示封面）<br>真机走设置菜单「副屏视频」 |
| `S` | **SELECT** | 筛选循环：全部 → 已刮削 → 缺封面 |
| `M` | **START** | 系统菜单 |
| `P` | **MENU** | 退出确认 |
| `Esc` | — | 关闭弹窗 |

**鼠标 / 触摸**：点击平台卡片 / 列表行 / 网格卡 / 轮播卡选中，**再点一次等于按 A**。

> **设计取舍**：界面上**不展示"这个游戏有哪些媒体"** —— 没有 ▶/◆ 之类的媒体类型标记，
> 也没有媒体源切换页签。下屏媒体区就是"有视频播视频、没视频放封面"，用户不需要关心媒体类型。
> 媒体类型的唯一入口是设置菜单里的「副屏视频」开关（想省电可关）。

## 4. 侧边栏开关

| 开关 | 作用 |
|---|---|
| **单屏兼容模式** | 隐藏下屏，把下屏内容压缩成主屏底部 118px 详情条；网格自动降为 4×2 |
| **副屏实时联动** | 关闭后下屏冻结，用于对比「有/无副屏联动」的信息量差异 |

## 6. 原型 → 真机的映射

| 原型 | 真机实现 |
|---|---|
| 程序化封面 `coverStyle()` | `data/media.py`：读 `<SYS>/Imgs/<name>.png` → 磁盘缩略图缓存 → LRU |
| `resolveMedia()` 降级 | `data/media.py`：有视频播视频 → 否则封面 → 否则 Logo → 占位图，**无手动切换入口** |
| `.videolayer` CSS 动画 | `data/video.py` 的 ffmpeg 管道：`-stream_loop -1 -vf scale=288:216,fps=15 -pix_fmt rgb24 -f rawvideo -` |
| 视频播放进度条 | 真机**不显示**（静音循环播放，进度条反而干扰） |
| 列表左图 `thumbMediaHTML()` | `data/media.py` 优先加载 `logo/<name>.png`，缺失回退 `Imgs/<name>.png` |
| `state.videoPaused` | 滚动 / 启动游戏时 `SIGSTOP` / `terminate()` |
| 侧栏 gamelist.xml 预览 | `data/sources/esde.py` 实际读写 `<SYS>/gamelist.xml`（见 DESIGN §6.8） |
| `gamelistEntry()` | ES-DE 写回：`<cover>` / `<video>` / `<marquee>` + `<favorite>` / `<playcount>` / `<lastplayed>` |

> **可扩展性**：`data/sources/` 是插件层。将来加 Pegasus（`metadata.pegasus.txt`）时，
> 只需新增 `pegasus.py` 实现 `MetadataSource` 的 5 个方法并注册进 `SOURCES`，
> 原型里看到的所有界面都不用改 —— 因为 UI 只认内部统一模型 `Game`（DESIGN §6.8.2）。
| 封面轮播 `renderCarousel()` | `ui/screens/game_carousel.py`：复用 196×272 磁盘缩略图，PIL 缩放一次完成 |
| 90ms 节流 `scheduleBottom()` | `ui/app.py` 主循环里的副屏脏标记 + 节流 + 停止滚动后强制刷新 |
| `launching` 态 | 写 `/tmp/retrostation_launch.cmd` → **停 ffmpeg** → 销毁窗口 → `execv` 让位 |
| 单屏详情条 `renderStrip()` | `ui/screens/bottom.py` 输出 PIL 图层 + 尺寸参数，单屏时 `paste` 到主屏 |
| 状态栏 | `core/hw.py` 读 `power_supply` / `thermal` / `backlight` |
| 平台核心显示 | `data/systems.py` 的 `core` 字段 |

**媒体目录约定**（原型与真机一致）

```
<SYS>/Imgs/<name>.png     封面   gamelist: <cover>（兼容 <image>/<thumbnail>）
<SYS>/video/<name>.mp4    视频   gamelist: <video>
<SYS>/logo/<name>.png     Logo   gamelist: <marquee>（兼容 <wheel>）
```

## 7. 已知简化

- **不解码真实视频**：下屏"视频"是 CSS 动画模拟（滚动光带 + 扫描线 + 进度条），
  用于验证**版式与降级逻辑**；真机性能已单独实测（288×216@15fps ≈ 19% 单核，见 DESIGN §6.5）
- 无真实封面 / Logo 图片，全部程序化生成（确定性渐变 + 首字 / 文字横幅）
- 元数据（厂商/年份/类型/评分/简介）为 mock，真机从 `gamelist.xml` 读或回退文件名
- 侧栏 XML 预览只展示**选中那一条**，真机会写全量条目
- 无真实扫描进度、无背光/音量调节的实际生效
- 启动流程为 1.6s 模拟，不真的拉起 RetroArch
